
# 🧠 Simon Game

A web-based memory game inspired by the classic *Simon* game. Test how far your brain can go!

## 🎮 Demo

🔗 https://github.com/pratiksha950/Simon-Game

## 🚀 Features

- Interactive color buttons with animations
- Random color sequence generation
- Tracks user input and checks correctness
- Level-based difficulty increase
- Game over and restart functionality

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

🧠 Rules<br>
1)Press any key to start.<br>
2)Watch the color sequence that flashes.<br>
3)Repeat the same sequence by clicking the buttons.<br>
4)The sequence grows by 1 color each level.<br>
5)One wrong move = Game over!
